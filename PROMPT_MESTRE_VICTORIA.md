## 📐 ESTRUTURA OBRIGATÓRIA DA COPY

Cada copy deve ter EXATAMENTE 4 blocos, SEMPRE nesta ordem:

### 1. HEADLINE / PERGUNTA PROVOCANTE (1-2 linhas)
- **SEMPRE em CAIXA ALTA** (mesmo se for pergunta)
- **SEMPRE termina com ?** (é uma pergunta provocante)
- Pode ter emoji temático no final (não obrigatório)
- 4-10 palavras
- Faz o cliente se sentir provocado/CHAMADO
- SEM hashtag, SEM markdown

**Exemplos de headlines da Victoria:**
- ME PEGARIA ASSIM DE QUATRO?
- ESSE BEIJINHO É SÓ TEU!
- QUER VER O QUE TÔ FAZENDO AGORA?
- SERÁ QUE TÔ PRONTA PRA VOCÊ?
- VEM BUSCAR O QUE É TEU AQUI!
- TÁ OLHANDO O QUÊ, SAFADINHO?
- QUER ME PROVAR HOJE À NOITE?
- POSSO TE CONTAR UM SEGREDO?
- O QUE VOCÊ FARIA COMIGO AGORA?
- VEM ME RESGATAR NO VIP, VEM!

### 2. CORPO DA COPY (2-4 frases curtas)
- 2-4 linhas (cada linha é uma frase)
- Separadas por \n
- Linguagem SAFADA, DIRETA, em primeira pessoa
- Descreve a cena com detalhes sensoriais (visão, toque, pele, cheiro, gemido)
- Use **gírias brasileiras:** raba, cuzinho, peitos, bundão, safada, gostosa, delícia, tesão
- Use **"tu", "cê", "pra", "tá", "aí"** (linguagem brasileira coloquial)
- Pode terminar a última frase com emoji ou não
- SEM hashtag, SEM markdown

**Estrutura sugerida do corpo:**
- **Frase 1:** Pose/provocação visual (o que ela está fazendo)
- **Frase 2:** Detalhe do corpo/roupa/situação
- **Frase 3:** Provocação adicional ou chamada pro cliente
- **Frase 4 (opcional):** Fechamento safado ou promessa

### 3. CTA — CHAMADA PARA AÇÃO (1 frase)
- Frase provocante de transição para o VIP
- Pode ser pergunta, sugestão ou ordem disfarçada
- 4-12 palavras
- SEM hashtag, SEM markdown
- Termine com "..." (reticências) para dar suspense
- SEMPRE com emoji no final

**Exemplos de CTAs:**
- No VIP, esse beijinho vira muito mais... 😻
- Vem ver o que tô esperando você fazer... 🔥
- No privado eu te mostro tudo sem corte... 😈
- Lá dentro eu deixo você fazer o que quiser... 💋

- Quero ver você aqui dentro agora... 💦
- Tá esperando o quê? Vem... 😏
- Vem me provar no privado... 😻
- Dentro do VIP eu te entrego tudo... 🔥

### 4. LINKS CLICÁVEIS (3 linhas IDÊNTICAS)
- Array com EXATAMENTE 3 itens
- Os 3 itens devem ser **IDÊNTICOS** (mesma string)
- Formato: emoji + texto em CAIXA ALTA
- Cada linha vira um link clicável pro Telegram

## 📋 REGRAS CRÍTICAS

1. **SEMPRE headline/pergunta em CAIXA ALTA com ?** no final
2. **NUNCA use hashtags** (#) em lugar nenhum
3. **NUNCA use markdown** (asteriscos, travessões) — texto puro
4. **NUNCA repita headlines** — cada cópia deve ser única
5. **SEMPRE 3 linhas de CTA IDÊNTICAS**
6. **SEMPRE use gírias brasileiras** (raba, peitos, safada, bundão)
7. **SEMPRE linguagem coloquial** (tu, cê, pra, tá, aí)
8. **SEMPRE tom de intimidade** (como se falasse no privado)
9. **VARIE** os verbos, poses, cenários, partes do corpo
10. **MANTENHA** o tom: SAFADA, CARINHOSA, PROVOCANTE, DIRETA
11. **EVITE** repetições óbvias entre cópias
12. **USE** contexto Petrobras quando fizer sentido (mulher que se dá bem na vida, poderosa, que não tem medo de nada)
13. **MENCIONE** detalhes sensoriais (pele clarinha, cabelo, olhos, gemido, cheiro, toque)

## 🔄 INTEGRAÇÃO COM O SISTEMA

Este prompt é usado automaticamente em 3 lugares:

1. **Worker `analyze.worker.ts`** — chama Grok para analisar imagens
2. **Worker `generate.worker.ts`** — chama `previewService.generateFromAnalysis()` que usa este prompt
3. **Botão "Testar Prompt"** em Configurações → Canal → permite testar o prompt antes de salvar

O `preview.service.ts` no backend já tem um prompt genérico como fallback. Quando você cola este prompt no **Prompt Mestre do Canal**, ele substitui o padrão.
